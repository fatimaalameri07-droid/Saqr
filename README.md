# صقر | Saqr
منصة وطنية تكشف روابط الاحتيال التي تستهدف الإمارات قبل وصولها للضحايا، وتتتبّع الحسابات التي تستقبل أموالهم.

AD team · هاكاثون الأمن السيبراني بالذكاء الاصطناعي (شرطة أبوظبي × 42 أبوظبي)

## الملفات
- saqr.pdf: العرض التقديمي
- صقر - وصف المشروع.pdf: وصف المشروع
- saqr_demo_with_voice.mp4: فيديو الديمو
- saqr_demo.html: نموذج أولي يعمل في المتصفح (نزّلوه وافتحوه في Chrome)
- saqr_code.zip: كود Python الكامل (المحرك، الرصد المبكر، لوحة Streamlit، التدريب)

## التشغيل
    pip install -r requirements.txt
    playwright install chromium
    streamlit run app.py
